This page plays back saved runs. Each one was recorded from the real pipeline, step by step, so the routing, rankings and prompts you see are what actually happened. The page itself holds no API keys and calls nothing, so it can only replay the questions that were recorded. To ask your own, run the project locally with uvicorn web.app:app.

Open any step to see the prompt that went to the model and the reply that came back.

    Ask a question, or pick a saved run, and the steps will show up here.

    Search results

    Vector search and keyword search each put forward candidates, the two rankings get fused, then the reranker rescores the shortlist. Ids that turn up in both searches are highlighted.

    The excerpts each search finds will show up here.

    Answer

    Excerpts are quoted from the UBC Vancouver Academic Calendar, and every result links to the page it came from. The calendar is the official word, so check it there before you act on anything you read here. This is a student project, not academic advising.
